# 加密备份与迁移

格式 1（`.sab`）用于本地与 VPS 之间的整库恢复。它是逻辑数据备份，不是 ZIP，也不包含可以执行的 SQL 或任意文件路径。

## 内容和边界

- 16 个明确允许的表：供应商 key、管理 API 凭证、四家网页登录状态、Parallel OAuth 客户端 ID、预设/设置、搜索访问凭证哈希、请求/调用、结果集合、Exa 手动余额与查询暂停状态。
- 源管理员口令、管理员登录会话、环境配置和本地 `encryption.key` 不进入备份。目标管理员访问保持不变；原有搜索访问凭证的哈希和撤销状态随备份恢复。
- 文件采用固定参数 scrypt（N=32768、r=8、p=1）派生密钥，AES-256-GCM 验证和加密整个 gzip 数据。随机 salt、nonce；认证头包含格式标识。文件和密码必须分开妥善保管。
- 文件最多 64 MiB，解压后的 JSON 最多 256 MiB；更大数据采用停机复制完整目录。旧格式不受支持时明确拒绝，不猜测字段含义。

## 恢复保证

导入首先验证加密认证、格式、表/列白名单、标量类型、JSON、关键业务数据及外键。未通过不会写入当前数据库。所有 SQL 结构来自目标本地代码/已有表结构，上传值仅作为参数绑定。

预览只返回时间与数量。确认标记绑定文件内容、当前数据库修改计数和服务实例；文件或目标状态变化后需要重新预览。确认恢复使用一次 SQLite 事务；失败回滚，不替换文件系统中的数据库或本地密钥。

导入后上游凭证重新加密到目标 Vault；保留原始 `calls.rowid`，使 Exa 手动校准的 `call_cursor` 不变。导入的未完成调用标为中断。成功后清除运行时搜索缓存、额度查询时间缓存和未完成的 OAuth 授权引导，已建立的供应商登录状态正常保留。

搜索、余额查询、后台批次、OAuth 网络操作尚未结束时无法开始备份/恢复。备份操作期间阻止新的写入和工具调用；健康检查和管理页只读查询仍可用。导出后仍应停止源实例，再在 VPS 恢复，防止旧实例更新供应商 refresh token。

## 接口

仅管理员 Cookie 会话可访问，普通搜索访问凭证不可调用。

- `POST /api/backups/export`：JSON `{password}`，返回 `.sab` 下载。
- `POST /api/backups/preview`：`application/octet-stream` 请求体；前 4 字节为大端元信息长度，随后为 UTF-8 JSON `{password}`，最后为 `.sab` 原始字节。
- `POST /api/backups/restore`：同上传格式，元信息额外包含预览返回的 `confirmation_token`。

密码不放在 URL 或自定义请求头中。接口响应不返回凭证明文，也不保存上传文件到磁盘。
