# 搜索警告与诊断

搜索和正文请求成功时，上游仍可能返回参数调整、来源限制等提示。网关保留警告类型与说明，结果页及用量日志中的“查询提示”可展开查看。提示本身不改变请求成功状态，也不会将 key 标记为限流或失效。

警告支持字符串以及含 `type` / `code`、`message` / `detail` / `description` 的对象。仅选取这些说明字段，不保存完整响应对象。保存前移除已知 key、常见令牌、Cookie、邮箱和链接中的身份信息、查询参数；最多展示 10 条上游警告，并限制说明长度。无法识别的字段显示说明不可用，不猜测具体原因。

调用日志新增可空的 `warnings_json` 列，搜索集合保留原有 `warnings: string[]` 接口。缓存、分页与服务重启后仍可读取。旧记录只保存数量时，读取结果与日志显示“历史记录仅保存了 N 项上游警告，未保存具体原因”，不修改原始集合或用新请求补写旧诊断。

## Parallel 实测

2026-09-14 使用最近一次用户搜索对应的 Parallel key，单独复测 `POST /v1/search`，模式 `advanced`，请求 `advanced_settings.max_results=40`。响应 HTTP 200、11 条结果，返回：

```json
{"type":"input_validation_warning","message":"Reducing max_results=40 to 20."}
```

该提示表示上游将请求数量上限从 40 调整为 20；不是免费 MCP 提示，也不代表额度不足。上限为 20 不保证返回 20 条。原请求只保存了警告数量，不能据此断言其丢失的原文与复测完全相同。网关仍显示实际发送的请求上限，具体上游调整由警告说明，不根据单个账号的响应修改所有账号配置。

[Parallel 官方 Search 响应](https://docs.parallel.ai/api-reference/search/search)、[请求参数说明](https://docs.parallel.ai/search/advanced-search-settings)

## 验证范围

- W1：搜索和正文提示可见；返回提示不影响正常结果与状态。
- W2：字符串、对象、空值、未知格式、长度/数量上限、敏感字段脱敏。
- W3：HTTP 返回、调用日志、缓存、分页、重启后的提示一致。
- W4：数据库增量迁移；旧集合、凭证与历史原因保持原样。
- W5：上游错误继续按错误处理，不将错误正文作为警告展示。
- W6：结果页和日志展开提示，桌面/手机排版、刷新后读取，以及文本不会作为 HTML 执行。
