# 搜索与正文读取故障

[返回 README](../README.md) · [客户端接入](clients.md)

搜索成功不代表每个命中网页都能抓取。目标网站拒绝访问、需要登录、返回安全验证页或没有可提取内容时，网关保留其他渠道的有效结果，并报告缺失来源。API key 有效与目标网页可读是两回事。

## 错误分类

| 代码 | 含义与处理 |
| --- | --- |
| `timeout` / 504 | 达到网关预设截止时间。检查调用耗时和预设；覆盖优先默认允许 120 秒。 |
| `cancelled` / 499 | 客户端取消或断开请求。将实际执行工具的客户端 HTTP / MCP 调用超时设为至少 180 秒；只调高网关超时无法延长客户端等待。 |
| `source_unavailable` | 上游无法读取目标网页。Exa 可报告源站 403 / 404；AnySearch 的 HTTP 422 + `extract_failed` 也属于此类，并非搜索参数错误。尝试普通网页链接、其他来源或搜索摘录。 |
| `source_blocked` | 返回了可识别的安全验证 / 拦截页。此类文本不会作为正文证据保存；网关不绕过网站验证。 |
| `empty_content` | 上游响应可解析，但没有正文。可换其他渠道或网页。 |
| `invalid_response` | 上游响应格式无法识别。保留错误以便排查，不能把未知文本当正文。 |
| `connection_error` / `upstream_error` | 网络连接失败或供应商暂时故障。网关只对适合重试的错误切换 key。 |

用量日志的“查询提示”保留安全的错误说明；结果中的失败渠道提供原因。网页级失败、客户端取消和正文解析失败不会让健康 key 进入冷却。上游已经报告的费用、credits 或 SKU 消耗即使正文不可用也会记录；没有账单数据的失败不会显示为免费。历史记录没有保存的详细原因与费用不会事后猜测补写。

网关按访问凭证和请求 ID 处理 MCP 取消通知，HTTP 连接断开也会停止尚未完成的上游调用。多个独立客户端应使用不同凭证；同一凭证同时复用相同请求 ID 时，网关不会猜测取消哪一个请求。已经完成的其他渠道结果仍可保留。

Parallel 全文读取未提供 `objective` 时，可能提示摘录缺少相关性目标。`full_content` 仍独立返回；这条提示本身不是调用失败或免费额度限制。[Parallel 全文设置](https://docs.parallel.ai/extract/advanced-extract-settings)

## 验证场景

| 编号 | 验收要求 |
| --- | --- |
| F1 | Keenable 原生 Title / URL / 正文、JSON 和 structuredContent 均可经 HTTP / MCP 读取，全文与计费保留；正文中的 Title / URL 行不被误切分。 |
| F2 | 空内容、非法格式、错误工具响应、私网 URL、超长正文正确拒绝或截断；错误响应不能成为证据；下一次正常调用恢复。 |
| F3 | AnySearch 422 `extract_failed`、Exa source status、Tavily failed_results、Parallel errors 归为网页读取失败；真正的参数、鉴权、限流错误保留原分类。 |
| F4 | 返回验证页时拒绝污染证据，普通讨论验证机制的文章及短文保留；其他渠道成功仍可分页读取。 |
| F5 | 正文不可用与解析失败时保留明确报告的消耗，未知费用保持未知；失败原因不泄漏凭证或原始错误正文，健康 key 不降级。 |
| F6 | MCP 客户端断开、显式取消与网关到期分别记录；取消后释放并发，不继续重试；正常长调用与后续调用保持可用。 |
| F7 | 既有 API、MCP、轮询、额度查询、备份恢复、历史清理与按客户端统计回归通过；生产升级保留数据且可回滚。 |
